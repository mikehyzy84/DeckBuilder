---
description: Create a new DeckBuilder project folder
argument-hint: "<Project Name>"
---

1. Run `python -m deckbuilder project new $ARGUMENTS`.
2. Ask Mike which brand applies: a slug from `BRANDS`, a brand folder path, or none. Write the answer to `brand:` in
   `project.yaml`.
3. Ask for the audience, objective, decision or takeaway, target slide count, presenter, and date. Leave any
   unknown field blank. Do not guess.
4. Tell Mike to drop source material into `context/` and any Claude Design export into `design-guide/`.
